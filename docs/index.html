現在のPSA10総額

前回比（比較可能なカードのみ）

各カードの最新相場を1枚ずつ合計。価格を取得できていないカードは含みません。前回比は各カードの履歴で最新のひとつ前の相場との比較です。相場日はカードごとに異なり、前日比や前回の自動更新時点との比較ではありません。下の期間切替には連動しません。

＋カードを追加

URLを貼り付けて次へ。GitHubで「Create」を押すと追加が始まります（ログインが必要です）。所有者・共同管理者向けの機能です。取得には数分かかり、結果はIssueで確認できます。

7日/30日前ちょうどの相場がない場合、その日以前でもっとも近い日付を比較元にします。
