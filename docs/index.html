現在のPSA10総額

各カードの最新価格に保有枚数を掛けて合計します。比較元にも現在と同じ保有枚数を使うため、枚数の増減による資産額の変化は含みません。差額と率は、比較できるカードだけを両側で同じ枚数にそろえて計算します。各期間はカードごとの最新相場日が起点です。基準日の価格がなければ、その日以前でもっとも近い相場日を使います。3か月前・6か月前は暦月で計算し、同じ日がなければ月末を使います。直近比は各カードの最新相場のひとつ前の価格です。相場日はカードごとに異なり、自動更新の実行日とは異なります。下の個別カードランキングの期間切替とは独立しています。

URLを貼り付けて次へ。GitHubで「Create」を押すと追加が始まります（ログインが必要です）。所有者・共同管理者向けの機能です。取得には数分かかり、結果はIssueで確認できます。

直近比は最新相場のひとつ前の価格と比較します。7日前・30日前・3か月前・6か月前は各カードの最新相場日から計算し、基準日以前でもっとも近い相場を使います。月単位の比較で同じ日がなければ月末を基準にします。比較できないカードは「-」で表示します。
